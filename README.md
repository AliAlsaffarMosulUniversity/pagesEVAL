# تطبيق ترقيم المستندات

## التشغيل على Windows

1. افتح `start.cmd` بالنقر المزدوج. يفتح التطبيق في المتصفح ويعمل محلياً.
2. ارفع ملف PDF أو Word بصيغة DOC أو DOCX.
3. أدخل رمز المحور وعدد الصفحات. اسحب الخانتين أو عدّل مواضعهما وأبعادهما كنسب مئوية.
4. اختر «معاينة الأرقام المثبتة» وافحص الصفحات، ثم «حفظ PDF بعد الترقيم».
5. الملف الناتج `numbered-document.pdf` يُحفظ بواسطة المتصفح. الأرقام والرمز جزء من محتوى PDF وتظهر في الطباعة.

## المتطلبات

Python 3.10 أو أحدث مع PyMuPDF. متوفرة على الجهاز الذي بُني عليه التطبيق. على جهاز جديد:

```
python -m pip install -r requirements.txt
```

تحويل Word على Windows يحتاج Microsoft Word مثبتاً. على الأنظمة الأخرى يحتاج LibreOffice في PATH أو متغير SOFFICE. لا تُشغّل وحدات الماكرو عند فتح ملفات Word للتحويل. لا تُعدّل الملفات الأصلية.

## الصفحات والمواضع

«ترقيم جميع صفحات المستند»: يجب أن يطابق العدد عدد صفحات المستند بعد تحويله إلى PDF، ويثبت التسلسل 1..N على جميع الصفحات.

«تكرار قالب من صفحة واحدة»: يكرر المستند ذي الصفحة الواحدة N مرة ثم يرقمه بالتسلسل.

الرمز يبدأ تقريبياً أعلى الصفحة، ورقم الصفحة أسفل اليمين، استناداً إلى الصورتين المرجعيتين. لا يوجد تعرف آلي على الخانات؛ اضبطها وفق المستند الفعلي. المواضع واحدة كنسبة من أبعاد كل صفحة؛ قد تحتاج معالجة المستندات ذات القوالب المختلفة على دفعات.

يحافظ التطبيق على محتوى PDF ويضيف كتابة شفافة فوقه دون طمس النص أو مسحه. استخدم خانات فارغة: لا يزيل التطبيق الأرقام أو الرموز الموجودة مسبقاً. إذا لم يتسع النص يرفض التصدير ويطلب تكبير الخانة أو تصغير الخط.

Word يُحوّل بمحرك Word على Windows للحفاظ على تنسيقه قدر الإمكان. الخطوط غير المثبتة والحقول الديناميكية قد تغير المظهر؛ المعاينة هي المرجع قبل التصدير. ملفات PDF الموقعة رقمياً تحتاج إعادة توقيع بعد أي تعديل.

## الخصوصية والحدود

التطبيق يستمع على 127.0.0.1 فقط ولا يرسل الملفات إلى خدمة خارجية. المستند الحالي في الذاكرة، وتحويل Word يستخدم مجلداً مؤقتاً يُنظف بعد التحويل. أغلق نافذة التشغيل لإنهاء الخدمة ومسح المستند من الذاكرة. الحد 60 ميغابايت و1000 صفحة. نافذة التطبيق مخصصة لمستند واحد في كل مرة.

## الاختبارات

```

```

تغطي التسلسل، بقاء المحتوى الأصلي بصرياً، الأبعاد، الصفحات المدورة، العربية، تكرار القالب، المدخلات غير الصالحة، الرفع والمعاينة والتصدير المحلي. جرى أيضاً اختبار تحويل Word ذي صفحتين وتثبيت الأرقام عليه بنجاح على جهاز البناء.
